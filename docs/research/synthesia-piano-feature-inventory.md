# Synthesia piano feature inventory

Research date: 2026-08-22. This inventory concerns Synthesia LLC's piano/keyboard learning application at `synthesiagame.com`, not the unrelated AI-video product with the same name. It is an evidence inventory only; it makes no porting or priority recommendations.

## Evidence and interpretation

Only first-party sources were used: Synthesia's current product pages, support guides, downloads and release archive, plus the Synthesia LLC listings in Apple's App Store and Google Play. A capability is listed as **confirmed current** when it appears in a current support guide, current product/licensing page, current store description, or the release notes for a build that remains current on at least one platform. Older release notes without current corroboration are isolated under **Historical, removed, or uncertain**.

The platform release lines are not synchronized. The public desktop download is Synthesia 10.9 from December 2022, Apple's current listing is 10.9.2 from February 2023, and Google Play shows a February 2025 Android update. A feature mentioned on one platform should not automatically be assumed to exist identically on every other platform. Sources were retrieved on 2026-08-22.

## Confirmed current capabilities

### Learning modes and primary workflows

- The song-learning workflow has three score-bearing modes: **Melody Practice, Rhythm Practice, and Recital**. Melody Practice waits until the player strikes the correct note before advancing and marks target keys with colored dots. The current first-party material found for this inventory names Rhythm Practice and Recital but does not precisely define their behavior, so this note does not infer it. A separate **Free Play** area supports unstructured playing, chord information, and recording. ([product page](https://www.synthesiagame.com/), [first-song guide](https://www.synthesiagame.com/support/guide/firstSong), [song/progress guide](https://www.synthesiagame.com/support/guide/choosingSongs), [10.9 release notes](https://www.synthesiagame.com/news))
- Users can play with the left hand, right hand, or both. Parts not assigned to the learner can be played automatically by Synthesia, allowing one-hand practice against the rest of the arrangement. ([product page](https://www.synthesiagame.com/), [song-setup guide](https://www.synthesiagame.com/support/guide/songSetup))
- The on-screen piano can be played by touch on supported mobile devices or through a typing-keyboard mapping when no digital piano is connected. ([App Store listing](https://apps.apple.com/us/app/synthesia/id579518445), [labels guide](https://www.synthesiagame.com/support/guide/labels))

### Falling notes, sheet music, and display

- A song can be displayed as falling note blocks, traditional sheet music, or both. Sheet music can be resized; the falling-note display can be disabled for a multi-line, full-screen notation view. Full-screen notation can be clicked or tapped for song navigation and can display bookmarks and loops. ([sheet-music guide](https://www.synthesiagame.com/support/guide/displaySheetMusic), [App Store listing](https://apps.apple.com/us/app/synthesia/id579518445), [release archive](https://www.synthesiagame.com/news))
- The falling-note view supports timeline seeking, pause/resume, horizontal keyboard zoom, and vertical look-ahead scaling. Horizontal presets include **Song Only**, the range of a connected keyboard (**My Keyboard**), and a custom zoom; touch users can pinch horizontally or vertically. ([first-song guide](https://www.synthesiagame.com/support/guide/firstSong))
- Independent key and falling-note labels support octave C markers, finger numbers, typing-keyboard mappings, English note names adjusted for the song's key, scale degrees, fixed-Do solfege, movable-Do solfege, and simplified A-G labels on white keys. Labels can be limited to the learner's assigned notes. ([labels guide](https://www.synthesiagame.com/support/guide/labels))
- Per-part display settings include color and visibility. Background parts are hidden by default but can be shown, while learner-assigned parts can also be hidden for more difficult practice. Auto Color assigns blue to left-hand parts, green to right-hand parts, and hides background parts. ([song-setup guide](https://www.synthesiagame.com/support/guide/songSetup))
- Current iPad release notes confirm adjustable label size and labels that track keyboard movement. Google Play's latest notes add ties to Android's sheet-music display. ([App Store listing](https://apps.apple.com/us/app/synthesia/id579518445), [Google Play listing](https://play.google.com/store/apps/details?id=com.synthesia.synthesia))

### Melody practice, fingering, and hand separation

- Finger-number hints use 1 for the thumb through 5 for the pinky. Built-in songs include hints, and users can add or edit hints directly while viewing falling notes by dragging a note to a displayed finger; typing-keyboard shortcuts can accelerate left- and right-hand entry. ([first-song guide](https://www.synthesiagame.com/support/guide/firstSong), [content-creation guide](https://www.synthesiagame.com/support/guide/contentCreators))
- Song parts can be assigned to Left Hand, Right Hand, Both/custom, or Background. Each part also has a selectable instrument, color/visibility, and sounded/muted state; settings can be copied to another part, applied to all parts, reset, and saved per song. ([song-setup guide](https://www.synthesiagame.com/support/guide/songSetup))
- A visual hand-assignment editor can divide a combined piano part. It supports an initial full-song split line, shorter correction lines, and assignment of individual notes with mouse, touch, and keyboard navigation. ([hand-splitting guide](https://www.synthesiagame.com/support/guide/assignHands))

### Practice controls, looping, and scoring

- Current product and store material confirms pause/resume, timeline seeking, speed controls, bookmarks, loops, and a built-in metronome. Full-screen sheet music shows bookmark and loop positions, and loop practice can restart after a configurable number of errors. ([first-song guide](https://www.synthesiagame.com/support/guide/firstSong), [App Store listing](https://apps.apple.com/us/app/synthesia/id579518445), [release archive](https://www.synthesiagame.com/news))
- Immediate feedback is paired with persistent per-song progress from 0 to 100. Group progress is the average of the songs in that group. The official guide says reaching 100 requires repeated, almost flawless performances with both hands across Melody Practice, Rhythm Practice, and Recital. ([product page](https://www.synthesiagame.com/), [song/progress guide](https://www.synthesiagame.com/support/guide/choosingSongs))
- The library can sort by points, title, last played date, play count, user rating, or difficulty. This is local progress tracking; current official pages do not advertise cloud synchronization or a current online leaderboard. ([song/progress guide](https://www.synthesiagame.com/support/guide/choosingSongs))

### MIDI and digital-keyboard support

- Synthesia accepts digital-piano input through USB-to-host or standard MIDI connections. A headphone/audio-only jack does not provide the MIDI data Synthesia needs. Device setup allows each input/output device to be enabled and calibrates the keyboard range by asking the user to play the lowest and highest keys. ([desktop connection chooser](https://www.synthesiagame.com/keyboards/help/desktop), [desktop USB guide](https://www.synthesiagame.com/keyboards/Help/desktop/usb), [keyboard information](https://www.synthesiagame.com/keyboards/info))
- iPad connection instructions cover wired USB/MIDI and compatible Bluetooth MIDI adapters. Android connection instructions cover USB On-The-Go and MIDI interfaces. Compatible Chromebooks can use MIDI devices through the Android app. ([iPad connection guide](https://www.synthesiagame.com/keyboards/Help/ipad_lightning/midi), [Android connection guide](https://www.synthesiagame.com/keyboards/Help/android/midi), [about/platform page](https://www.synthesiagame.com/about))
- The current product description says Synthesia works with the lights in most lighted keyboards. In Melody Practice, upcoming notes can be sent to the keyboard lights. All MIDI-device features, including light support, are available in the free version for compatibility testing. ([product page](https://www.synthesiagame.com/), [keyboard information](https://www.synthesiagame.com/keyboards/info), [unlock page](https://www.synthesiagame.com/unlock))
- The current desktop release, 10.9, added multiple input instruments. The iPad 10.9 notes also mention new key-light options, and Free Play recordings now capture pedal and other MIDI events. ([release archive](https://www.synthesiagame.com/news), [App Store listing](https://apps.apple.com/us/app/synthesia/id579518445))

### Songs, import, library, and Music Store

- Synthesia loads standard **MIDI** and **MusicXML** files as songs. WAV and MP3 are explicitly distinguished as rendered audio and cannot be used as the note/event definition for a playable song. ([about/platform page](https://www.synthesiagame.com/about), [desktop song-import guide](https://www.synthesiagame.com/support/guide/addSongs))
- On Windows and macOS, a song can be opened directly from the operating system or discovered by scanning user-selected folders; default scan locations include the Desktop, and USB drives and network locations can be added. ([desktop song-import guide](https://www.synthesiagame.com/support/guide/addSongs))
- On Android 11 and later, `.mid` and `.midi` folder scanning remains available, while MusicXML (`.musicxml`, `.mxl`, `.xml`), `.synthesia` metadata, and SoundFonts require Android's file picker. The iPad app uses Apple's Files app for song management. ([Android import guide](https://www.synthesiagame.com/support/guide/addSongsAndroid), [release archive](https://www.synthesiagame.com/news))
- The product includes 150+ songs, of which 20+ can be used fully in the free version. The one-time unlock enables the full included library, removes the demo time limit on outside songs, and enables recording. A separate licensed Music Store sells commercial arrangements. ([unlock page](https://www.synthesiagame.com/unlock), [Music Store](https://www.synthesiagame.com/store))
- The song library supports built-in and custom/nested groups, previews, deletion of custom songs, hiding the built-in library, user-set rating and difficulty, sorting, and text search. Advanced searches can target metadata such as `composer:` and `tags:`. ([song/progress guide](https://www.synthesiagame.com/support/guide/choosingSongs), [content-creation guide](https://www.synthesiagame.com/support/guide/contentCreators))
- `synthesia://` links can launch the installed app and download/open a directly linked song. The official guide says these links do not currently deliver `.synthesia` metadata bundles or complete groups. ([content-creation guide](https://www.synthesiagame.com/support/guide/contentCreators), [link generator](https://www.synthesiagame.com/urlmaker))

### Notation, fingering, and metadata authoring

- The official, supported, free Synthesia Metadata Editor creates `.synthesia` sidecar files without modifying the underlying MIDI or MusicXML song. A sidecar is associated with a hash-derived unique song ID, so editing the underlying music file can break that association. ([content-creation guide](https://www.synthesiagame.com/support/guide/contentCreators), [downloads](https://www.synthesiagame.com/download))
- Metadata fields include title, subtitle, composer, arranger, copyright, license, difficulty, rating, tags, hand assignments, and finger hints. The editor can bulk-edit songs, import locally saved hand/finger data from Synthesia, and build nested song groups. The guide notes that license metadata is stored but is not displayed in Synthesia. ([content-creation guide](https://www.synthesiagame.com/support/guide/contentCreators))
- Synthesia's content tools edit part/hand assignments, finger hints, presentation metadata, instruments, colors, and visibility. No current official guide documents direct editing of imported note pitch, onset, duration, tempo maps, or notation engraving in a piano-roll or score editor. This is a documentation-based absence, not proof that no hidden workflow exists.

### Audio, instruments, Free Play, and recording

- Each song part can be changed to another instrument and independently sounded or muted. Synthesia can use an external keyboard as both MIDI input and output; the official keyboard guide recommends a device with the full 128 General MIDI instruments when background arrangements will be played through it. ([song-setup guide](https://www.synthesiagame.com/support/guide/songSetup), [keyboard information](https://www.synthesiagame.com/keyboards/info))
- Windows, Android, and iPad include a MIDI synthesizer that can load custom SoundFonts. The current guide documents SF2, load-on-demand for large sets, the built-in Voice Crystal sound set, a test function, and reverb; iPad 10.9 adds SF3 support, and Android's picker accepts `.sf2`, `.sf3`, and similar SoundFont files. The official SoundFont guide does not include macOS. ([SoundFont guide](https://www.synthesiagame.com/support/guide/changeSoundFont), [Android import guide](https://www.synthesiagame.com/support/guide/addSongsAndroid), [App Store listing](https://apps.apple.com/us/app/synthesia/id579518445))
- The unlocked Free Play screen contains a simple MIDI recorder. It can overdub up to six tracks, assign each recorded track its own instrument and color, adjust the common tempo, retain an unfinished session after navigating away or closing the app, and save the result into the song library. Optional **Snap to Nearest** adjusts recorded note start/end timings toward the beat. ([recording guide](https://www.synthesiagame.com/support/guide/recording))
- Synthesia 10.9's Free Play view supports choosing a key signature for more chord information, Roman-numeral chord names, multiple input instruments, a gear menu for view/style-volume controls, and recording pedal/other MIDI events. ([release archive](https://www.synthesiagame.com/news), [App Store listing](https://apps.apple.com/us/app/synthesia/id579518445))
- Current official material describes MIDI recording and playback, not microphone/audio recording, VST hosting, or a direct audio-render/export workflow.

### Platforms, devices, licensing, privacy, and accessibility

- The current desktop download is Synthesia 10.9 for 64-bit Windows 7 or later and macOS 10.9 or later; Apple Silicon is supported. The current Apple listing requires iPadOS 9.3 or later and reports Apple Vision compatibility. Google Play supports phone, tablet, and Chromebook form factors and now requires Android 6 or later. The product site recommends a tablet-sized device for Android even though the current store listing also exposes phone support. ([downloads](https://www.synthesiagame.com/download), [about/platform page](https://www.synthesiagame.com/about), [App Store listing](https://apps.apple.com/us/app/synthesia/id579518445), [Google Play listing](https://play.google.com/store/apps/details?id=com.synthesia.synthesia))
- The unlock is a one-time purchase rather than a subscription, and future upgrades are included. A website unlock key works simultaneously on Windows, Mac, iPad, and Android. An iPad or Android in-app purchase is tied to devices using the purchasing store account. Educational organizations are licensed per seat and receive volume pricing. The displayed price is promotional/region-sensitive and should not be treated as a stable product capability. ([unlock page](https://www.synthesiagame.com/unlock), [App Store listing](https://apps.apple.com/us/app/synthesia/id579518445))
- Both official store disclosures say the developer does not collect data. Google additionally says no data is shared with third parties and data in transit is encrypted. ([App Store listing](https://apps.apple.com/us/app/synthesia/id579518445), [Google Play listing](https://play.google.com/store/apps/details?id=com.synthesia.synthesia))
- Apple says the developer has not declared which accessibility features the iPad app supports. Zoom, scalable labels, multiple label notations, configurable colors, and touch/typing/MIDI input are usability aids, but they should not be described as certified screen-reader, Voice Control, reduced-motion, high-contrast, or other accessibility support without further evidence. ([App Store listing](https://apps.apple.com/us/app/synthesia/id579518445), [first-song guide](https://www.synthesiagame.com/support/guide/firstSong), [labels guide](https://www.synthesiagame.com/support/guide/labels))

## Historical, removed, or uncertain capabilities

These items appear in official historical material but do not have enough current, cross-platform corroboration to place in the inventory above without qualification.

- **MusicXML notation semantics:** Synthesia 10.8 introduced MusicXML loading but explicitly said the additional musical information beyond MIDI was not yet used to draw sheet music. Android later added ties, but current official documentation does not say that full MusicXML notation semantics are now preserved on every platform. Loading and playback are current; full-fidelity engraving is uncertain. ([release archive](https://www.synthesiagame.com/news), [Google Play listing](https://play.google.com/store/apps/details?id=com.synthesia.synthesia))
- **Older notation details:** Historical release notes mention rests, key/time signatures, staccato, note/measure highlighting, down-stems, smarter staff selection, fixed-width notation, and page-turn effects. These features are likely cumulative, and down-stems/full-screen notation have relatively recent corroboration, but the current guides do not enumerate the full rendering set. ([release archive](https://www.synthesiagame.com/news), [App Store listing](https://apps.apple.com/us/app/synthesia/id579518445))
- **Advanced control remapping:** The 2012 release notes describe remapping song controls to typing keys and MIDI controls—for example, pitch bend for seek, the lowest piano key for pause, and the modulation wheel for speed. Current hand-assignment help still says shortcuts are configurable, but no current dedicated guide confirms the entire old MIDI-control mapping surface. ([release archive](https://www.synthesiagame.com/news), [hand-splitting guide](https://www.synthesiagame.com/support/guide/assignHands))
- **Sustain and small-keyboard accommodation:** Historical notes document sustain-pedal playback behavior and automatic handling of notes outside a smaller keyboard's range. Current recording notes confirm that pedal events can be captured and the current zoom guide knows the connected keyboard's range, but automatic out-of-range transposition/auto-play is not currently documented. ([release archive](https://www.synthesiagame.com/news), [App Store listing](https://apps.apple.com/us/app/synthesia/id579518445), [first-song guide](https://www.synthesiagame.com/support/guide/firstSong))
- **Themes and custom backgrounds:** Shareable/custom color themes and custom background images appear only in 2012-2013 release notes. Their availability in current desktop or mobile builds is unverified. Dark Mode appears in the iPad 10.6 release history but is not advertised in the current product description. ([release archive](https://www.synthesiagame.com/news), [App Store listing](https://apps.apple.com/us/app/synthesia/id579518445))
- **Localization:** The release archive cumulatively names English, Spanish, French, German, Russian, Brazilian Portuguese, Traditional Chinese, Italian, Dutch, Slovenian, Polish, Thai, Catalan, Turkish, and Japanese. Apple's current listing reports only English. Because those official sources conflict, current per-platform UI-language coverage is uncertain; the historical list should not be treated as an audited current matrix. ([release archive](https://www.synthesiagame.com/news), [App Store listing](https://apps.apple.com/us/app/synthesia/id579518445))
- **Profiles and competition:** Named local profiles, online score identities/competition, user-profile statistics, and “competition-ready” scoring appear in old release notes. Current guides confirm local progress but do not advertise an account, cloud sync, or live leaderboard, so those older online/social claims are not treated as current. ([release archive](https://www.synthesiagame.com/news), [song/progress guide](https://www.synthesiagame.com/support/guide/choosingSongs))
- **Video export:** The separate Synthesia Video Creator remains downloadable only as version 10.4 from 2017. The download page warns that it sometimes fails and says the tool will return in Synthesia in the future. The release archive mentions Windows AVI export for that old tool. Native video recording/export is therefore not established as a current Synthesia 10.9 feature. ([downloads](https://www.synthesiagame.com/download), [release archive](https://www.synthesiagame.com/news), [official video-use guidance](https://www.synthesiagame.com/video))
- **Forum-based details:** Synthesia's official forum is currently paused because of abusive traffic. The current support site links to it, but old forum posts and linked 10.9 developer blogs could not be fetched reliably. This limits verification of detailed Free Play/label options beyond the public release notes. ([forum pause](https://www.synthesiagame.com/forum/), [support index](https://www.synthesiagame.com/support))

## Key evidence limits

- This is a documentation and store-listing inventory, not hands-on certification of every desktop/mobile build or every MIDI/lighted-keyboard model.
- Synthesia's main site has stale platform language in places: for example, its About page still says Android 4.1+, while the newer Google Play listing says Android 6+. The newer platform listing was preferred for current minimums.
- A feature's presence in an old release note suggests it was shipped, not that it remains present unchanged. Such claims were kept in the historical/uncertain section unless current official material corroborated them.
- “No current official documentation found” is not the same as a definitive product absence. This especially affects note editing, audio export, accessibility, controller remapping, profiles, themes/backgrounds, and cross-platform MusicXML fidelity.
