# Make the Practice journey accessibly operable by default

Openthesia adopts a WCAG2ICT-informed Windows Accessibility Baseline for the complete learner-facing Practice journey: choosing a Song and Chart, configuring and conducting a Practice Session, using guidance, loops, and bookmarks, reading results, and returning. This is an engineering baseline rather than a formal WCAG, legal-compliance, or screen-reader conformance claim. Narrator support requires a separate Microsoft UI Automation architecture because Dear ImGui exposes no native accessibility tree.

The journey honors Windows text scaling through 225% and Per-Monitor V2 DPI changes. Surrounding controls reflow without losing content or operation while the spatial piano roll may scroll or zoom and has a simplified textual current-target alternative. Pointer targets are at least 24 device-independent pixels. Keyboard operation is complete without a pointer: Tab and Shift+Tab traverse controls, arrows operate composites, Enter or Space activates, Escape dismisses or returns, and persistent focus cues use at least a two-pixel perimeter with 3:1 contrast. Computer-keyboard piano input cannot consume navigation or focused-control input.

Color never carries hand, target, selection, timing judgment, or control state alone. Normal text meets 4.5:1 contrast while large text, necessary graphics, control boundaries, and focus cues meet 3:1; Windows contrast themes override decorative palettes. Practice Status remains visible independently of optional Learner + Chart guidance and identifies pitch with octave, hand, and state. Icon commands have visible text where space permits and a keyboard-reachable labelled overflow otherwise.

Device Settings own an effects preference with `System`, `Reduce`, and `Full`, defaulting to `System`. Reduced effects remove decorative matrix motion, title pulsing, glow, transparency-dependent cues, and transitions while keeping underlying music behavior unchanged. Functional falling-note motion may remain only with static current and next-target text plus keyboard-operable Pause and Stop. No effect flashes more than three times per second.

Accessibility guarantees are not hidden behind a master mode. Versioned Device Settings follow Windows scaling, contrast, and animation preferences by default, preserve existing visual choices when allowed, and fall back safely when absent or malformed. Learner + Chart guidance preferences remain separate. Automated verification targets settings persistence, platform policy, Practice semantics, and command routing through public interfaces; keyboard traversal, focus rendering, scaling, contrast themes, and monitor transitions also require a manual Windows matrix.
