# Model Practice Sessions with a deterministic Chart-centered module

A Practice Session is one comparable attempt over a fixed Chart range and evaluation-relevant configuration, with Wait for Notes, Play in Time, and Recital as Practice Modes while Required Hands, Accompaniment, tempo, guidance, and visual view remain orthogonal choices. A deterministic in-process Practice Session module owns lifecycle, Chart-clock policy, Practice Targets, Accompaniment decisions, assistance, and ordered Practice Events behind a small `TryStart`/`Handle` interface; ImGui, DryWetMIDI, persistence, and later scoring are adapters or consumers outside that seam. The first production slice replaces the rendering-driven learning gate with Wait for Notes and integrates the existing Song/Chart/Learner foundation, while section repetition and scoring remain deferred to their roadmap decisions.
