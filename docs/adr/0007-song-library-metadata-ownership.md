# Separate shared Library metadata from Learner organization

The Song Library composes data with different owners rather than storing one undifferentiated library record. Descriptive tags are shared Song Metadata, arrangement difficulty is shared Chart Metadata, groups and favorites are personal Learner Song Data, and practice choices and outcomes remain Learner Chart Data. Song-level Practice Progress summaries are derived from Chart-specific Practice Progress instead of becoming another stored score.

This boundary lets multiple local Learners organize the same catalog independently without duplicating shared musical facts or allowing one Learner's preferences to change another's Library. Search and filters may combine these owners in one view, but persistence and migration must keep them distinct.
